# Trip Data Logger

## Overview
Trip Data Logger is a web application that allows users to import CSV files from the Volvo App, organize trip data, and perform analytics to view driving statistics.

## Features

Trip Data Logger offers a variety of capabilities to enhance your trip data management and analysis:

- **Visualize All Trips**: View all trips along with their respective data in an organized manner, making it easy to analyze your driving patterns.
- **Statistics Overview**: Access a comprehensive overview of statistics and performance counters, including aggregated data to understand your driving habits better.
- **Custom Statistics**: Build your own statistics using the collected values, allowing for personalized insights into your driving behavior.
- **Map Features**: Utilize map functionalities to visualize the starting and destination points of all trips at a glance, providing a geographical context to your data.
- **Additional Features**: 
  - Set a cost per kWh to gain insights into budgetary and cost-related information.
  - Add trips to favorites for quick access.
  - Add or edit trip notes for better context and reminders.
  - Use trip labels to categorize and organize your trips effectively.

## Future Improvements

We are continuously working to enhance the Trip Data Logger experience. Future improvements may include:

- **Track Recharges**: Monitor and log recharges for electric vehicles to better understand energy consumption.
- **Share Trips and Statistics**: Enable users to share their trips and statistics/graphs with others for collaborative insights.
- **Export/Import Functionalities**: Allow users to export and import data for easier management and sharing.
- **Other Features**: We welcome suggestions for additional features that could improve the user experience.

## Prerequisites
Before you begin, ensure you have the following installed:
- A web server with PHP and MySQL support.

## Installation Steps

### Step 1: Install a Web Server
To set up a web server with PHP and MySQL support, follow this comprehensive tutorial: [How to Install a Web Server with PHP and MySQL](https://www.digitalocean.com/community/tutorials/how-to-install-linux-apache-mysql-php-lamp-stack-on-ubuntu-20-04).

### Step 2: Configure Database Connection
1. Locate the `db.php` file in the project directory.
2. Update the file to point to your MySQL database.

Replace DB_HOST, DB_USERNAME, DB_PASSWORD, and DB_NAME with your actual database credentials.

## Usage
Import your CSV files from the Volvo App.
Analyze and visualize your trip data through the web interface.
